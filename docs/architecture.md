# 架构与语义边界

## 为什么契约采用最小规范超集

真实引擎在事件对象、标的编码、时间切片、组合模型、订单类型和成交模型上并不一致。把某一引擎的固定字段写进论文策略，只会得到名义上的可移植性。PSRC 定义引擎中立的最小规范超集，并在加载策略代码前协商引擎能力画像。

可移植性的准确含义是：策略只声明一次需求，系统给出两个诚实结果之一——所选引擎能在已记录语义下满足需求，或编译失败。它不意味着抹平引擎差异，也不承诺不同成交模型得到相同 PnL。

## 分层

1. **可选上游交接层**：外部工具可以把论文论断转为 `PaperStrategySpec` 或策略包；本项目不实现论文正文解析或自动代码生成，只定义可审计的交接对象。
2. **声明层**：策略包目录提供 manifest、入口源码、实际数据和训练请求；声明解析不执行策略代码。
3. **编译层**：检查 Contract 主版本、支持等级、能力画像、动作、数据类型、字段、标的、周期与最低沙箱，并把源码证据哈希绑定到执行计划。
4. **兼容层**：只应用白名单转换，并输出含版本、理由、哈希、参数、影响行数、可逆性和关闭开关的不可变记录。
5. **运行时层**：在源码策略检查通过后加载包入口，控制生命周期、内容寻址产物和推理调用。
6. **适配器层**：转换规范事件、动作和账户，同时保留引擎声明的成交、费用、队列、延迟及时间戳语义。
7. **报告层**：同时生成机器证据与中文可读结果。

## 跨引擎适配流程

```text
策略需求 + 实际数据 + 引擎能力 + 运行策略
                  |
             静态契约编译
        ┌─────────┴─────────┐
        |                   |
  不可满足：结构化失败    可满足：ExecutionPlan
                            |
                 规范事件/动作/账户边界
                 ┌──────────┼──────────┐
              Reference  Backtrader  Nautilus
                 └──────────┼──────────┘
                     统一 RunBundle
```

因此，Contract 不需要预先复制每个回测引擎的全部固定字段。稳定核心表达跨引擎共同语义；确实无法规范化的字段进入扩展命名空间；无法忠实转换的能力明确拒绝。LEAN、Qlib 和 vn.py 画像用于证明扩展路径，而不是虚构其执行成功。

## 确定性与禁止前视

输入事件包含事件发生、可用和接收三个时间戳。决策只有在 `available_time` 后才能使用该事件。参考引擎让指令从下一事件开始生效；Backtrader 使用默认下一 bar 执行；NautilusTrader 的原生 bar 回调可能在回调 bar 收盘价成交，因此适配器将规范指令延迟一个事件后再提交。

跨引擎测试证明决策流及成交方向、数量、时间戳一致，同时允许已声明的价格模型差异。规范哈希会在 JSON 编码前递归排序无序集合，属性测试保护这一稳定性不变量。

## Agent 的位置

论文解析或代码生成 Agent 属于项目外的可选上游。PSRC 只提供结构化交接对象，并通过 `psrc author audit` 审计已有的 `PaperStrategySpec` 与 manifest；它不会调用 LLM，也不会从 PDF 或网页生成策略。`AgentAuditReport.runtime_authority_granted` 在 Schema 中固定为 `false`。Agent 不能挑选替代引擎、降低沙箱级别、自动批准有损转换或把论文歧义伪装成事实。最终仍需经过人工复核、Schema 校验、能力编译、源码证据绑定和隔离运行。

## 信任边界

Python AST 静态检查是 import 前强制门禁，但不是单独的安全隔离边界。严格模式的边界是外层非 root 容器：无网络、只读根文件系统、最小可写挂载、资源限制和 `noexec` 临时目录。策略包在 import 前完成 manifest、输入哈希、能力与源码检查，严格加载还要求不可仅靠环境变量伪造的容器标记。仅画像引擎无法通过默认最低支持等级。

本项目明确不认证的生产问题包括：内核加固、镜像签名、经纪商凭据、实盘风险限额、交易所一致性及产物恶意软件扫描。
