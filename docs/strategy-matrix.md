| 类别 | 策略 | 主要差异 |
| --- | --- | --- |
| 规则 | SMA 交叉 | 分钟 OHLCV、目标仓位 |
| 规则 | Donchian 突破 | 日线 OHLCV 突破 |
| 规则 | 配对 z-score | 双标的日线均值回归 |
| 规则 | L1 微价格 | 买卖一价及数量 |
| 规则 | L2 不平衡做市 | 深度感知限价单提交/改单 |
| 规则 | TWAP 执行 | 定时切片与直接订单 |
| 监督学习 | Logistic 方向 | 梯度训练二分类方向 |
| 监督学习 | Ridge 收益率 | 正则化连续收益率 |
| 监督学习 | Gaussian 成交量突破 | 生成式类别似然 |
| 监督学习 | L1 逆向选择 | 报价不平衡感知机 |
| 监督学习 | L2 成交概率 | 稀疏 Logistic 深度模型 |
| 监督学习 | 截面排序器 | 日线多标的质心排序 |

| 强化学习 | Double-Q 订单簿库存 | 拆分估计器的 L2 库存控制 |
| 强化学习 | Dyna-Q 配对 | 学习配对状态模型及规划更新 |
| 强化学习 | 线性 Actor-Critic 配置 | 连续目标权重策略 |

每个可训练示例都依次执行训练、内容寻址保存、完整性校验重载，再通过同一 Contract 进入推理/回测。每个策略目录包含完整机器 manifest、包内入口源码、数据 manifest、精确输入事件、可选训练请求与中文 Strategy Card；`psrc demo all` 从这些目录发现并运行策略，而不是绕过目录调用内置 factory。包内入口在 manifest、输入哈希、能力和源码策略全部验证成功后才允许 import。

“18 个”不是把同一 SMA 参数复制 18 次。证据门禁会对策略类别、数据种类、周期、必要字段和动作空间生成契约指纹，并要求至少 12 种有实质差异的形状；当前矩阵还覆盖单/双/多标的、bar/L1/L2 及信号/目标仓位/直接订单等差异。
